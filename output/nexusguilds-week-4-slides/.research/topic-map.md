# Topic Map — nexusguilds-week-4-slides

## TOPIC CLUSTERS

### 01 apis-fundamentals — What an API Is and How AI Model APIs Work
- **Slides:** 5
- **Scope:** Core concept of APIs explained via the restaurant analogy plus the four foundational API concepts that govern any AI model integration.
- **Prerequisite concepts:** client-server model, HTTP request/response cycle, API authentication and API keys, rate limiting, API endpoints, LLM/AI model API basics
- **Research queries (English):**
  - "What is an API and how do APIs work for beginners"
  - "How do AI model APIs work request response authentication"
  - "API authentication API keys best practices explained"
  - "API rate limits and endpoints explained simply"
  - "Restaurant analogy for explaining how an API works"

### 02 integration-patterns — Five Integration Patterns for Connecting AI Systems
- **Slides:** 6
- **Scope:** The five ways systems integrate with APIs (synchronous, event-driven, batch, streaming, tool use), with event-driven as the entry point for no-code automation.
- **Prerequisite concepts:** synchronous vs asynchronous processing, event-driven architecture and webhooks, batch processing, streaming responses and token streaming, LLM tool use / function calling
- **Research queries (English):**
  - "Common integration patterns for connecting to APIs"
  - "Event-driven architecture and webhooks explained for automation"
  - "Synchronous vs asynchronous vs batch API processing"
  - "Streaming responses from LLMs how token streaming works"
  - "LLM tool use and function calling explained"

### 03 tool-spectrum — The Four-Tier Automation Tool Spectrum (No-Code to Full Code)
- **Slides:** 7
- **Scope:** The four tiers of automation tooling (no-code, low-code, AI-assisted code, full code), their tradeoffs, and the 80/20 rule for tier selection.
- **Prerequisite concepts:** no-code platforms (Zapier, Make), low-code platforms (Retool, n8n), AI-assisted coding (Cursor, Replit), SDKs (Python/Node.js), maintenance burden, 80/20 heuristic
- **Research queries (English):**
  - "No-code vs low-code vs full code automation tools comparison"
  - "Zapier vs Make no-code automation platforms overview"
  - "Low-code platforms n8n Retool when to use them"
  - "AI-assisted coding tools Cursor Replit for automation"
  - "When to use no-code vs custom code 80/20 rule automation"

### 04 automation-anatomy — Anatomy of an AI Automation (Trigger → AI → Delivery)
- **Slides:** 8
- **Scope:** The universal three-stage structure of any AI automation, anchored by a worked email-classification example.
- **Prerequisite concepts:** automation triggers (email, form, file, schedule), LLM processing tasks (classify, summarize, extract, generate), output delivery actions, prompt design for automations (CRFT prompts)
- **Research queries (English):**
  - "Anatomy of an AI automation trigger processing action"
  - "How to structure an AI automation workflow trigger AI delivery"
  - "Email classification automation with AI example"
  - "Writing effective prompts for automated AI workflows"
  - "Triggers and actions in automation platforms explained"

### 05 build-automation-hands-on — Building the Same Automation Three Ways and Your Own
- **Slides:** 11, 12
- **Scope:** Implementing one automation across Zapier, Make, and cURL/Python, then building one's own from a menu of five practical automation patterns.
- **Prerequisite concepts:** Zapier visual builder, Make HTTP modules and visual flows, cURL and scripting API calls, build-difficulty vs control tradeoff, common business automations (email analysis, meeting summary, application screening, ticket routing)
- **Research queries (English):**
  - "How to build an email classification automation in Zapier"
  - "Calling an AI API from Make HTTP module tutorial"
  - "Calling an AI API with cURL command line example"
  - "Comparing no-code vs API call for the same automation tradeoffs"
  - "Common business workflow automations with AI examples"

### 06 process-mapping — Process Mapping and Choosing the Right Tier
- **Slides:** 13
- **Scope:** A workshop method for mapping real business processes to tool-spectrum tiers using volume, complexity, builder/maintainer, and scale criteria.
- **Prerequisite concepts:** business process mapping, evaluating process volume and frequency, decision criteria for tooling (who builds, who maintains, logic complexity, scale), effort estimation
- **Research queries (English):**
  - "How to map business processes for automation"
  - "How to decide which automation tool or tier to use"
  - "Criteria for choosing no-code vs low-code vs code automation"
  - "Estimating effort for automating a business process"
  - "Prioritizing processes to automate by volume and complexity"

### 07 course-framing-and-orchestration-preview — Module Framing, Deliverables, and the Path to Orchestration
- **Slides:** 1, 2, 3, 4, 9, 10, 14, 15, 16
- **Scope:** Course/module structure, the automation-as-a-spectrum framing story, session agenda, deliverables and portfolio, and the preview of moving from automation to multi-step agent orchestration.
- **Prerequisite concepts:** AI user vs AI integrator, automation as a spectrum, learning deliverables/portfolio artifacts, multi-step workflow chaining, autonomous AI agents, AI orchestration vs single automation
- **Research queries (English):**
  - "Difference between an AI user and an AI integrator"
  - "From single automations to multi-step AI workflows orchestration"
  - "What are autonomous AI agents that make decisions"
  - "Chaining AI steps into multi-step workflows"
  - "Cross-departmental AI workflow design overview"
