# Topic Map — nexus-guilds-ai-foundations-week-2-slides

## TOPIC CLUSTERS

### 01 model-selection-thesis — Why No Single Model Wins
- **Slides:** 2, 5
- **Scope:** The core thesis that "best model" is meaningless without task context; model choice needs a defensible, criteria-based framework.
- **Prerequisite concepts:** large language model (LLM) basics, what differentiates frontier models, optimization trade-offs (quality vs. speed vs. cost), the notion of task-fit vs. absolute "best"
- **Research queries (English):**
  - "how to choose the right large language model for a task 2026"
  - "why there is no single best AI model trade-offs quality speed cost"
  - "LLM benchmarks limitations real-world task evaluation"
  - "enterprise multi-model AI strategy why companies use several LLMs"

### 02 model-families-overview — The Six Model Families
- **Slides:** 6, 7, 8, 9, 10
- **Scope:** Profiles of the six major model families (Claude, GPT, Gemini, DeepSeek, Llama, Grok), their makers, signature strengths, named tiers, and caveats.
- **Prerequisite concepts:** model vendors (Anthropic, OpenAI, Google, DeepSeek, Meta, xAI), open-weight vs. closed/proprietary models, reasoning/extended-thinking models, multimodality, web grounding, self-hosting and fine-tuning basics, content moderation/filtering
- **Research queries (English):**
  - "comparison Claude GPT Gemini DeepSeek Llama Grok 2026 strengths"
  - "Anthropic Claude Opus Sonnet Haiku model tiers capabilities"
  - "OpenAI GPT-4o o3 o4-mini reasoning models difference"
  - "Google Gemini 2.5 Pro Flash context window web grounding multimodal"
  - "DeepSeek V3 R1 open-weight cost self-hosting GPU requirements"
  - "Meta Llama open-source fine-tuning on-premise vendor lock-in xAI Grok real-time data"

### 03 selection-framework — The 6-Dimension Selection Framework
- **Slides:** 11, 12
- **Scope:** The six evaluation dimensions (Quality, Speed, Cost, Context Window, Specialisation, Ecosystem) and the 3-step weighted decision process for applying them.
- **Prerequisite concepts:** context window / tokens, time-to-first-token vs. total latency, price per million tokens, weighted decision matrix / weighted scoring, defining requirements before evaluation
- **Research queries (English):**
  - "framework for evaluating and selecting LLMs dimensions quality cost context"
  - "weighted decision matrix for AI model selection"
  - "LLM context window explained tokens"
  - "how to benchmark LLMs on your own task before adopting"

### 04 tiers-and-cost — Model Tiers, Pricing & the Cost Iceberg
- **Slides:** 13, 14, 15
- **Scope:** Capability/price tiers across vendors, the 80/20 cost-routing strategy, and total cost of ownership beyond token pricing (infrastructure, integration, switching/lock-in).
- **Prerequisite concepts:** flagship vs. balanced vs. lightweight tiers, input vs. output token pricing, model routing for cost reduction, GPU infrastructure costs, integration/maintenance cost, vendor lock-in / switching costs, total cost of ownership (TCO)
- **Research queries (English):**
  - "LLM API pricing comparison input output tokens 2026"
  - "model tiering strategy reduce AI costs flagship vs balanced"
  - "LLM routing cost optimization cheaper model for simple tasks"
  - "total cost of ownership self-hosted LLM GPU infrastructure"
  - "AI vendor lock-in switching costs prompt portability"

### 05 hands-on-comparison-matrix — Hands-On: Model Comparison & Selection Matrix
- **Slides:** 18, 19, 20
- **Scope:** The practical exercises — head-to-head model comparison on real tasks and building/peer-validating an AI Tool Selection Matrix deliverable.
- **Prerequisite concepts:** structured prompting (CRFT), rubric-based output evaluation, mapping task categories to ranked dimensions, primary vs. fallback model selection, justification/documentation of decisions, peer validation/scenario stress-testing
- **Research queries (English):**
  - "how to build an AI tool selection matrix template"
  - "comparing LLM outputs side by side evaluation rubric criteria"
  - "primary and fallback model strategy for production AI workflows"
  - "evaluating creative code and analytical LLM tasks scoring"

### 06 course-structure-and-bridge — Course Structure, Deliverable & Week 3 Bridge
- **Slides:** 1, 3, 4, 16, 17, 21, 22
- **Scope:** Course/week framing, session agenda and dividers, portfolio context, and the teaser/setup bridge to Week 3 (AI-assisted development).
- **Prerequisite concepts:** cohort/pre-reading + in-class learning model, cumulative skills portfolio, no-code app builders (Replit Agent, Bolt.new), agentic coding environments (Cursor, Claude Code), prerequisite tooling setup (GitHub)
- **Research queries (English):**
  - "AI-assisted development no-code app builders 2026 overview"
  - "Replit Agent Bolt.new describe app plain English builder"
  - "agentic coding tools Cursor Claude Code pair programming"
  - "structuring a practical AI upskilling course pre-reading in-class"
